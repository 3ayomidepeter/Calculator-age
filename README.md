# AGE CALCULATOR

This is a simple web-based age calculator that allows users to enter their birth date and calculates their age in years, months, and days. The app uses the Luxon library for date manipulation and calculation. https://roadmap.sh/projects/age-calculator

## Features

Input your birth date via a date picker.
Click "Calculate" to see your age in years, months, and days.
Displays a result in a readable format.
Technologies Used
HTML: Structure of the webpage.
CSS: Styling the webpage (optional for your design).
JavaScript: Age calculation logic using Luxon.
Luxon: A powerful JavaScript library to work with dates and times.
Getting Started
Prerequisites
Ensure you have a modern browser that supports ES6 JavaScript modules and the DateTime functionality.

Running the project locally
Open the index.html file in your preferred browser.
Enter your birth date using the date picker.
Click the "Calculate" button to display your age.
Example Usage
Open the browser and load the index.html file.
Enter a date, for example, 1990-05-15.
Click the Calculate button, and the age will be displayed in the format "You are X years, X months, and X days."
